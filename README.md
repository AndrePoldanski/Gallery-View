Gallery View

Gallery View is a lightweight photo viewer designed for photographers who prefer viewing images against a clean dark background without the distractions of traditional slideshow software.

The project began after noticing how much better photographs looked in the crop tool of Apple Photos, where the image is displayed with breathing space around it on a dark background.

Rather than creating another photo editor, Gallery View focuses on one thing:

Displaying photographs beautifully.

Features
Clean black background viewing
Alternative dark grey and competition grey backgrounds
Adjustable image display size
Optional white border
Swipe navigation on iPad and touch devices
Keyboard navigation on PC and Mac
Full-screen friendly
No animations
No transitions
No subscriptions
Runs directly in a web browser
Keyboard Shortcuts
Key	Function
←	Previous photo
→	Next photo
H	Show/Hide controls
B	Border On/Off
G	Cycle background colours
1	70% image size
2	80% image size
3	85% image size
4	90% image size
+	Increase image size
-	Decrease image size
Supported Formats

Works best with:

JPEG (.jpg)
PNG (.png)
HEIC (.heic)
